# Haji Leather — Artisan Leather Atelier & Bespoke Craft Website

A static website for **Haji Leather**, an artisan leathercraft studio dedicated to traditional vegetable tanning, hand saddle-stitching, bespoke private commissions, and architectural leatherwork since 1984.

> **Design Directive**: As requested, this website contains **no products or product catalogs**. It focuses purely on brand heritage, craftsmanship standards, materials, bespoke disciplines/services, the living patina journey, workshop atelier details, and private commission inquiries.

---

## ✨ Features & Sections

1. **Top Announcement Bar**: Atelier status, founding year (EST. 1984), and quick inquiry link.
2. **Navigation Header**: Monogram crest logo, smooth navigation anchors, mobile-friendly toggle, and direct "Commission Inquiry" CTA.
3. **Hero Section**:
   - Masterful headline: *"Shaped by Tradition. Defined by Character."*
   - Key atelier highlights: 1984 founding, 100% full-grain hides, 0 machine shortcuts, lifetime structural guarantee.
4. **Heritage & Legacy**:
   - Narrative of slow, deliberate craftsmanship.
   - Quote by Master Artisan Haji.
   - Double-visual gallery highlighting hide preparation and traditional saddle stitching.
5. **Standards of Purity (Four Pillars)**:
   - Grade-A Full-Grain Hide (uncorrected, tightest grain).
   - Botanical Vegetable Tanning (oak bark, chestnut tannins, zero chrome).
   - Two-Needle Saddle Stitching (French linen thread hand-waxed with beeswax).
   - Beeswax Edge Burnishing (friction-rubbed glass edge seal).
   - Leather Grade Comparison Table (Full-Grain vs Top-Grain vs Bonded).
6. **The Five Stages of Master Execution**:
   - Step 01: Hide Curation & Grain Mapping
   - Step 02: Precision Hand Drafting & Skiving
   - Step 03: Diamond Pricking & Awl Piercing
   - Step 04: Two-Needle Saddle Stitching
   - Step 05: Friction Burnishing & Nourishment
7. **Interactive Patina Simulator**:
   - Interactive 3-stage visual toggle:
     - *Day 1: Virgin Natural* (pale biscuit, firm temper)
     - *Year 3: Honey Golden* (amber glow, supple memory)
     - *Year 10+: Deep Amber Heirloom* (espresso luster, glassy sheen)
   - Real-time swatch color shifts and metrics for depth, luster, and suppleness.
8. **Bespoke Services (Zero Off-The-Shelf Products)**:
   - Private Bespoke Commissions (custom folios, desk sets, travel chests).
   - Architectural Leather Accents (handrails, leather wall tiles, desk inlays).
   - Corporate Milestone & Heritage Gifting (crested executive suites).
   - Heirloom Restoration & Preservation (archival conditioning, restitching).
9. **The Atelier & Workshop Experience**:
   - Workshop hours, guild address, and direct atelier communication line.
10. **Frequently Asked Questions**:
    - Accordion addressing why there are no off-the-shelf products, lead times, custom hides, and care tips.
11. **Bespoke Commission Inquiry Form**:
    - Inputs for Client Name, Email, Phone, Discipline of Interest, Preferred Hide, Timeline, and Vision Notes.
    - Full client-side validation, error handling, and a dedicated confirmation summary.
12. **Site Footer**:
    - Heritage manifesto, navigation, commission disciplines, and "The Atelier Journal" newsletter signup.

## 🚀 How to View the Website

You can view the website directly in any web browser:

### Option 1: Double-click `index.html`
Open `index.html` directly in your default browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (PowerShell / Command Prompt)
Run the following command inside this directory:
```powershell
python -m http.server 8080
```
Then open your browser and navigate to:
```
http://localhost:8080
```
